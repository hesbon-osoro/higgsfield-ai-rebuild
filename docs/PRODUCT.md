# Product notes: what I kept, what I changed, what I cut

## What Higgsfield is

An AI creative suite: text or reference image → image, image → video, with **camera
motion presets** (dolly, crash zoom, orbit, bullet time…) as its signature. Around that
core it has grown a lot of surface: 15+ third-party models (Kling, Veo, Sora, Seedance,
Wan, Nano Banana, Seedream, FLUX…), dozens of one-click "apps" and VFX presets, Soul ID
character training, lipsync, upscale, Cinema Studio (virtual camera bodies and lenses),
an agent, a ChatGPT plugin, an MCP server, a film festival, and credit plans.

## The problems I saw as a user

1. **Choice paralysis before the first result.** You pick a page, then a model, then
   settings, before you've made anything. Most people want "a good image of X", not
   "Seedream 4 vs Nano Banana Pro".
2. **You don't know the cost until you've committed.** Credits differ by model, duration
   and resolution. The number that matters, *what does this click cost me*, isn't where
   you decide.
3. **The core loop is split up.** Image generation and video generation are separate
   places. The obvious move, "I like this image, now make it move", means leaving one
   tool and re-uploading into another.
4. **Results lose their recipe.** Explore does show prompts, which is great, but your own
   history doesn't let you remix with one click (same settings, tweak one thing).
5. **Sign-up wall before value.** You can't feel the product without an account.

## What this rebuild is

**One studio, one loop: prompt → image → motion → library.**

| Decision | Why |
| --- | --- |
| **Single composer** with an Image / Video switch, not a page per model | One place to create; switching mode keeps the prompt |
| **"Auto" model by default**, with each model shown by what it's *for* (speed, realism, style) and its cost | Removes the first decision; experts can still choose |
| **Cost on the Generate button** ("Generate · 12 credits"), updated live as settings change, with a balance check before submit | Cost is visible at the moment of decision |
| **Failed generations refund automatically** and show in a credit ledger | Credits feel trustworthy, not like a slot machine |
| **"Animate" on every image** opens video mode with that image as the start frame | Joins up the loop that's split in the original |
| **Camera motion presets as a visual grid with live animated previews** | This is Higgsfield's best idea, so it's first-class and not buried |
| **Every result keeps its recipe** (prompt, model, preset, aspect, seed): Remix, Reuse prompt, Animate | History becomes a starting point, not an archive |
| **Explore feed uses the same recipe model**, with "Use recipe" loading it into the composer | Learn by copying what works |
| **Guest session with free starter credits, no sign-up** | Value in the first 10 seconds; an account can come later |

## What I cut, on purpose

- **15+ third-party models.** Four engines, described by intent, cover the decision
  that matters.
- **Apps and VFX marketplace, Soul ID training, lipsync, upscale, Cinema Studio
  lens/body simulation.** Each is a product of its own. The core loop comes first.
- **Agent, ChatGPT plugin, MCP, film festival, enterprise.** Distribution and
  marketing, not the creative loop.
- **Real payments.** Top-ups are clearly marked demo credits.
- **Accounts and OAuth.** Guest sessions cover the assignment. The data model has a
  `users` table, so real auth is an add-on rather than a rewrite.

## Honesty about generation

There are no paid model API keys in this build.

- **Images are real**: generated by AI Horde, a free crowdsourced Stable Diffusion network.
  Each engine maps to different real checkpoints, and the queue position and ETA are
  shown live. (Pollinations was the first choice. Mid-build, its anonymous tier started
  answering HTTP 402 with x402 payment demands, so it was dropped.)
- **Video is a motion render**: the start frame is animated in the browser with the
  selected camera move (dolly, orbit, crash zoom…). It shows the product flow and the
  preset system honestly. It isn't a diffusion video model, and the UI says so.
- Providers sit behind one server-side interface (`src/server/providers`), so plugging
  in fal.ai, Replicate or a first-party model is one file plus an env var.

## Stack

TypeScript · Next.js (App Router) · GraphQL (graphql-yoga, served from a Next route) ·
Postgres (Drizzle ORM) · TanStack Query on the client.
