# Parallax: a Higgsfield rebuild

**Live:** https://higgsfield-ai-rebuild.vercel.app · **Agent logs:** [`.agent-logs/`](.agent-logs) ·
**Capture setup:** [`CAPTURE-TEST.md`](CAPTURE-TEST.md) · **Product notes:** [`docs/PRODUCT.md`](docs/PRODUCT.md)

Higgsfield is an AI studio for images and cinematic camera moves. It has also grown into a
maze of 15+ models, dozens of apps, and separate pages for each step. Parallax keeps the
part that makes Higgsfield special, **camera motion over a generated frame**, and rebuilds
the loop around it:

> **prompt → image → camera move → library**, in one studio.

No sign-up needed: open the link and you get a guest session with 150 credits.

## What I changed, and why

| Higgsfield | Parallax | Why |
| --- | --- | --- |
| A page per model, choose a model first | One composer. **Auto** picks an engine from your prompt and shows which one it picked | Removes the first decision for new users; experts can still override |
| Cost depends on model, duration, resolution; unclear until you commit | **Cost on the Generate button**, live, with a balance check first | You see the price when you decide |
| Credits spent on failed jobs are hard to track | **Automatic refunds** plus a full **credit ledger** | Credits feel trustworthy |
| Image and video are separate tools | **Animate** on every image opens video mode with that frame | Joins up the core loop |
| Motion presets listed by name | **Preset grid with live previews on your own frame** | Choose by seeing, not by guessing names |
| History is an archive | Every result keeps its **recipe** (prompt, engine, aspect, seed, move): **Remix** reloads it, seed included | Change one thing at a time |
| Explore shows prompts | Explore items are **recipes**: *Use this recipe* loads everything into the studio | Learn by copying what works |

**What I cut:** most third-party models, the apps and VFX marketplace, Soul ID training, lipsync,
upscale, Cinema Studio's lens simulation, agents and plugins, and real payments. Details and
reasoning are in [`docs/PRODUCT.md`](docs/PRODUCT.md).

## What's real and what's demo

- **Images are real.** They're generated by [AI Horde](https://aihorde.net), a free crowdsourced
  Stable Diffusion network. Each engine maps to different real checkpoints: *Photo* uses
  Deliberate, Realistic Vision and AbsoluteReality; *Illustration* uses Anything v5 and
  Abyss OrangeMix. Waits vary from seconds to a few minutes, and the UI shows the live
  queue position and ETA the provider reports.
- **Video is a motion render**: 16 camera moves (dolly, crash zoom, vertigo, orbit, bullet
  time, handheld…) applied to the frame in the browser. It isn't a diffusion video model.
  One function (`cameraAt` in `src/lib/motion.ts`) drives both the live player and the
  **.webm export**, so the download matches the preview.
- **Credits are real accounting with demo top-ups**: atomic debits, exactly-once refunds,
  and a ledger. Top-ups add credits without payment.
- Providers are job-shaped (`submit` / `check`) behind `src/server/providers`. A paid model
  (fal.ai, Replicate, a first-party one) is a new file there plus an env var.

## Architecture

```
Next.js 16 (App Router) ─┬─ /api/graphql   graphql-yoga schema: viewer, generations, explore, ledger, mutations
                         ├─ /api/assets/:id immutable image bytes from Postgres
                         └─ React client    TanStack Query; lists poll while jobs are in flight
Postgres (Drizzle) ── users · assets (bytea) · generations · credit_ledger
Provider ── AI Horde: submit → check (throttled, advanced on each poll) → store image → SUCCEEDED
```

- **No background workers.** Jobs move forward when the client polls, and each job's
  provider check is throttled. This fits serverless: no request waits for a model.
- **Money-like logic in the database**: debits use `UPDATE … WHERE credits >= cost`. A
  refund only happens on the `PROCESSING → FAILED` transition, so it can't happen twice.
  Stale jobs are failed and refunded on the next read.
- **Guest sessions**: signed HttpOnly cookie → `users` row. Real auth would attach an
  identity to that same row.

## Run locally

```bash
docker run -d --name hf-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=higgsfield -p 55432:5432 postgres:17-alpine
cp .env.example .env
npm install
npm run db:migrate
npm run db:seed        # loads curated Explore recipes from seed/
npm run dev
```

Optional: set `HORDE_API_KEY` (free at aihorde.net) for better queue priority.

## How this was built

With Claude Code (Opus 5.5). Every prompt and final response is captured automatically by
hooks into [`.agent-logs/`](.agent-logs) (see [`CAPTURE-TEST.md`](CAPTURE-TEST.md)). Every
change went through branch → PR → merge. The PR history shows the order of work, including
dead ends: Pollinations went behind a paywall mid-build, and AI Horde's size budget shrinks
under load.
